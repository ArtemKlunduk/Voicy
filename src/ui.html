Режим прогрева модели

Сразу — модель загружается при старте listener'а. Команды выполняются быстрее (~1 сек), но занимает ~700 МБ RAM постоянно.

При первой команде — экономит RAM. Первая команда после старта подождёт загрузку модели (~5–10 сек), остальные идут быстро.

Голосовой ассистент

Как работает: скажи «дай ответ» → задай вопрос голосом → ИИ отвечает кратко и озвучивает ответ.

Gemini API (основной): введи ключ в настройках — ответы за 1–2 секунды, бесплатный tier 1500 запросов/день.
Fallback: без ключа используется локальная модель (работает офлайн, но медленнее — ~30–50 сек).

How to get a Gemini key

Why? With a Gemini key the AI answers in 1–2 seconds with excellent quality. Without a key it falls back to a slow local model (~30–50 s per answer).

1. Go to aistudio.google.com/app/apikey
2. Click "Create API key"
3. Copy the key (starts with AIza...)
4. Paste into the "Gemini API key" field in Voicy settings
5. Click "check" → should show ✓

Отправляй сообщения голосом

Сначала залогинься в Telegram через QR-код: открой Telegram на телефоне, зайди в Settings → Devices → Link Desktop Device и отсканируй код во вкладке Telegram. Потом добавь друзей кнопкой «Импорт из Telegram» и задай каждому короткий алиас — вместо длинного имени просто «Даник». Теперь говори: «Напиши Данику привет, как дела?» — и сообщение уйдёт моментально.

«Напиши Данику привет»

Открывай сайты голосом

Не нужна мышка и клавиатура — просто скажи. «Открой ютуб котики» — и YouTube сразу откроется с поиском котиков. Работает с YouTube, Google, TikTok и Twitch. Можно уточнять: «Открой гугл погода в москве» — браузер откроется с готовыми результатами. Говори естественно, как будто просишь друга.

«Открой ютуб котики»

Включай музыку без рук

Скажи «включи» и назови трек — например, «включи Кизару дежавю». Voicy найдёт песню на YouTube Music и запустит встроенный плеер с обложкой и регулятором громкости. Управляй кнопками: пауза, следующий трек. Хочешь ещё от этого исполнителя? Скажи «включи что-нибудь похожее» — включит следующий трек автоматически.

«Включи Кизару дежавю»

Голосовой ИИ-ассистент

Скажи «дай ответ» и задай любой вопрос — например, «дай ответ что такое чёрная дыра». Локальная нейросеть найдёт ответ и Voicy озвучит его вслух. Всё работает офлайн — не нужен интернет и не нужен API-ключ. На вкладке Models можешь выбрать модель: Qwen (быстрая), Llama (сбалансированная) или Gemma (мощная).

«Дай ответ что такое чёрная дыра»

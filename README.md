# 🤖 Voice TG Helper

Голосовой помощник для отправки сообщений в Telegram. Работает полностью в фоне, без открытых окон браузера. Использует **Whisper** для распознавания речи и **Telethon** (MTProto API) для отправки сообщений.

---

## ⚡ Быстрый старт

### 1. Установка зависимостей

Открой папку проекта и выполни:

```bash
pip install -r requirements.txt
```

> При первом запуске Whisper скачает модель `base` (~150 МБ). Если точность русской речи не устроит — поменяй `WHISPER_MODEL` в `config.py` на `small` или `medium`.

### 2. Получение API-ключей Telegram

1. Зайди на [https://my.telegram.org/apps](https://my.telegram.org/apps)
2. Создай приложение (любое название)
3. Скопируй **api_id** и **api_hash**
4. Вставь их в файл **`config.py`**:

```python
API_ID = 12345678          # <-- твой api_id (число)
API_HASH = "a1b2c3d4..."   # <-- твой api_hash (строка в кавычках)
```

### 3. Настройка контактов

Открой **`contacts.txt`** и добавь друзей:

```text
609101832 - Даник, Данику, Данила, Даниле
4759384 - Тима, Тиме, Тим
```

- **ID** — Telegram User ID (число).
- Через запятую указывай варианты имён, которые ты произносишь (в любом регистре).

### 4. Установка автозагрузки

Дважды кликни по файлу **`install.py`** (или запусти `python install.py`).

Он создаст:
- `run_background.vbs` — для ручного запуска без консоли
- Ярлык в папке автозагрузки Windows — чтобы стартовал вместе с системой

### 5. Первый запуск

Дважды кликни по **`run_background.vbs`**.

Что произойдёт:
1. Скрипт запустится **без консоли** (полностью в фоне).
2. Появится окно для ввода номера телефона Telegram.
3. Затем окно для кода из Telegram.
4. Если включена 2FA — окно для пароля.
5. После успешного входа окна больше не появятся — сессия сохраняется.

> Все события пишутся в файл **`app.log`** в папке проекта.

### 6. Использование

1. **Зажми** `Alt + X` — снизу посередине появится анимированный эквалайзер (началась запись).
2. **Скажи** команду, например:  
   `«напиши Данику я занят»`  
   `«напиши Тиме поехали на речку»`
3. **Отпусти** `Alt + X` — запись остановится, пойдёт распознавание и отправка.
4. **Результат:**
   - ✅ **Зелёная галочка** — сообщение отправлено.
   - ❌ **Красный крестик** — ошибка (команда не распознана, контакт не найден, не удалось отправить).

> Чтобы остановить скрипт — найди процесс `pythonw.exe` в Диспетчере задач и заверши его.

## 📁 Структура проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | Точка входа, глобальные хоткеи (`Alt+X`), оркестрация |
| `overlay.py` | Плавающее окно поверх всех приложений (эквалайзер / ✅ / ❌) |
| `core.py` | Запись звука, Whisper (распознавание), парсинг команды |
| `telegram_sender.py` | Отправка сообщений через Telethon (MTProto API) |
| `config.py` | Настройки, API-ключи, путь к эквалайзеру |
| `contacts.txt` | Список контактов (ID + имена) |
| `install.py` | Установка автозагрузки и создание `run_background.vbs` |
| `app.log` | Логи работы (создаётся автоматически) |

## 🔧 Настройка

В **`config.py`** можно изменить:

- `API_ID` / `API_HASH` — ключи от Telegram.
- `WHISPER_MODEL` — модель Whisper (`tiny`, `base`, `small`, `medium`, `large`).
- `SAMPLE_RATE` — частота дискретизации (по умолчанию 16 000 Гц).

## ❓ Частые проблемы

**Не срабатывает `Alt+X`**  
→ Проверь, что скрипт запущен. Открой `app.log` — там будут ошибки. Если прав не хватает — запусти `python main.py` от имени администратора один раз для первичной настройки.

**Whisper не распознаёт речь**  
→ Проверь микрофон по умолчанию в системе. Попробуй модель `small` вместо `base`.

**Не отправляется сообщение**  
→ Убедись, что `API_ID` и `API_HASH` заполнены. Проверь `app.log`. Убедись, что ID контакта правильный и ты уже взаимодействовал с этим пользователем.

**Окно входа в Telegram не появляется**  
→ Скрипт запущен через `pythonw`, поэтому окна должны появляться. Проверь `app.log` на наличие ошибок. Попробуй запустить `python main.py` (с консолью) для диагностики.

## 📝 Примечание

- Эквалайзер загружается из папки **`эквалайзер/`** (`icons8-аудио-волна-80.gif`).
- Вся работа идёт в фоне — ни браузер, ни консоль не нужны после первого запуска.
- Для удаления из автозагрузки удали файл `VoiceTGHelper.vbs` из папки:  
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`

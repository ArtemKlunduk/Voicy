что внутри

Не приложение. Просто клавиша.

Распознаёт локально

Whisper или Parakeet‑v3 работают на твоём компьютере. В облако ничего не уходит — никогда.

Отправляет в Telegram

Один раз вошёл в аккаунт — и забыл. Сообщения уходят от твоего имени, как обычные.

Одна клавиша

Зажми Alt+X, скажи что-нибудь, отпусти. Это весь интерфейс. Хоткей можно поменять.

Открытый код

Весь код на GitHub. Можно почитать, форкнуть, собрать самому. Лицензия — MIT.

Бесплатно. Навсегда.

Никаких подписок, лимитов, корпоративных тарифов. Сделано для людей, не для рынка.

Выбери контакт

Один раз — кому будут отправляться сообщения. Список можно менять.

Конфиг — один файл. Без UI.

Voicy читает voicy.toml рядом с .exe. Можешь поменять модель распознавания, язык и хоткей — или просто запустить с дефолтами.
